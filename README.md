The images and metadata.csv files that are used by the model are contained in the 10x10 folder. The metadata.csv file is at the end of that folder.
Clone the repo and put the contents of the Unity folder into RNN_small_hippocampal_model/data/ and run.  

Notebook order: 
  - original dictionary notebook
  - single rnn notebook
  - connected rnn notebook
  - manifold visualization notebook
  - pearson correlation confusion matrix notebook (contains the euclidean distance confusion matrix as well)
